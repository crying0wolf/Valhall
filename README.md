## Standard Project Folder Structure

Every project folder follows the same internal layout:

```
Project_X/
├── images/                   # Artwork, screenshots, concept art, visual assets
├── reference/                # Mood boards, research notes, inspirations, references
├── code/                     # Source code, scripts, and programming files
├── formalities_and_licenses/ # Contracts, licenses, legal documents, credits
├── sound/                    # Music tracks, sound effects, voice recordings
├── docs/                     # Design documents, notes, and written documentation
└── exports/                  # Final output files and deliverables
```

To start a new project, copy any existing project folder and rename it. Update the `README.md` inside with a description of the new project.
